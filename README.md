# OOP80US · In-class walkthrough (Units 1–3)

**Group D · Saturday lab** · Open this folder and work **one exercise at a time** with the lecturer.

GitHub Classroom accept is optional. You can also:

```bash
git clone https://github.com/ium-oop80us-2026/oop80us-walkthrough.git
cd oop80us-walkthrough
```

Or download the ZIP from the green **Code** button on GitHub.

## Compile and run (every exercise)

```bash
g++ -Wall -Wextra ex1_program/starter.cpp -o ex1
./ex1
```

Change `ex1_program` / `ex1` for exercises 2–5.

## The five exercises

| # | Folder | Concept | Unit |
|---|---|---|---|
| 1 | `ex1_program/` | A complete C++ program (skeleton + IPO) | 1 |
| 2 | `ex2_division/` | Integer division vs double | 2 |
| 3 | `ex3_swap/` | Swap needs a temporary box | 2 |
| 4 | `ex4_equals/` | `=` writes; `==` asks | 3 |
| 5 | `ex5_bands/` | `else if` bands + `&&` | 3 |

Each folder has:

- `starter.cpp` — what you open first (some lines are wrong or incomplete on purpose)
- `README.md` — what to do and what the output should be
- `solution.cpp` — look only after you have tried
