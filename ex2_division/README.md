# Exercise 2 — Integer division (Unit 2)

When both sides of `/` are `int`, C++ throws the fraction away.

## Task

1. Run `starter.cpp` with no changes. Write down what it prints for 7 and 2.
2. Change the program so it also prints the **true** quotient (3.5).
3. Keep the integer result as well, so you can compare.

## Expected output (inputs 7 then 2)

```
Enter a: 7
Enter b: 2
Integer division: 3
Real division: 3.5
```
