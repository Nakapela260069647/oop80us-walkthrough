# Exercise 5 — Bands and AND (Unit 3)

## Task

1. Complete the `else if` chain so:

   | marks | print |
   |---|---|
   | 80 or more | `Band: A` |
   | 70–79 | `Band: B` |
   | 50–69 | `Band: C` |
   | below 50 | `Band: F` |

2. Then read `hasID` (1 = yes, 0 = no). Print `Eligible` only when **marks >= 50 AND hasID == 1**. Otherwise print `Not eligible`.

## Expected output (inputs 78 then 1)

```
Enter marks: 78
Band: B
Has ID? (1=yes 0=no): 1
Eligible
```
