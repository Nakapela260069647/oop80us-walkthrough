# Exercise 4 — `=` writes; `==` asks (Unit 3)

## Task

1. Run the starter. You will see that `marks` **changes** to 50 even though you typed 78.

3. Run again with 78. Marks must stay 78. Print `Not fifty`.

```
Enter marks: 78
Not fifty
marks is still 78
```
